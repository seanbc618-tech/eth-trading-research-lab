# Teaching walkthrough / 教学说明

## 1. Reproduce / 复现

Run the README commands from the repository root. The first run produces fills; the `--risk-limit 100` run rejects entry requests because the teaching host requests approximately USD 1,000 of exposure. Rejections appear in JSON with reasons and an audit trail, not as successful fills.

按 README 运行。默认演示产生模拟成交；限额 100 的演示会拒绝约 1,000 美元的入场请求。JSON 保留拒绝原因及审计事件，拒单不会被记作成交。

The dataset is generated by `python3 examples/generate_data.py`. It is a transparent triangular path with small deterministic open gaps; it is deliberately simple and has no connection to historical market data. Never interpret its performance as an estimate of returns.

数据由 `python3 examples/generate_data.py` 生成，是带有确定性开盘跳动的简单三角价格路径，与真实行情无关。它只服务于工程演示。

## 2. Replace a plugin / 替换插件

From Python with `src` on the import path:

```python
from pathlib import Path
from quantlab.demo import load_candles, run
from quantlab.market_data.replay import SignalAction, SignalProposal

class BuyAndHoldTeaching:
    def on_confirmed_candle(self, context):
        if len(context.history) == 1:
            return SignalProposal(SignalAction.LONG, "teaching-first-confirmed-bar")
        return None

report = run(
    load_candles(Path("examples/synthetic_hourly.csv")),
    strategy_factory=BuyAndHoldTeaching,
    strategy_id="teaching-buy-and-hold-v1",
)
print(report["metrics"])
```

This leaves an open position marked at the last close. The host computes size and checks limits; the plugin never computes fill quantities. Choose a distinct strategy ID when changing logic. The dataset/result hashes identify input and output, not all Python code; the release checksum inventory separately identifies source files.

这个示例期末仍持仓，按最后收盘价估值。数量和限额由宿主处理。改变策略逻辑应改变策略 ID；结果哈希不是完整代码锁，源码身份另由发布文件校验清单记录。

## 3. Inspect / 核对

- `report.json`: assumptions, metrics, fills, per-order risk decisions, audit stages, pending final-bar signals and result hash.
- `equity.csv`: equity and fractional drawdown after each hourly close.
- `report.html`: bilingual visual summary, usable offline.

最后一根的信号没有下一根开盘，不会凭空成交，保留在 `pending_signal_ids` 中。单笔成交的 `decision_time` 与 `execution_time` 可能相同，因为上一根收盘恰好等于下一根开盘；数据来源 K 线必须不同。

## 4. Research lessons / 研究方法

The release demonstrates mechanics, not an OOS study. A future empirical study would need a documented dataset license and coverage, a predeclared hypothesis, development/validation separation, realistic execution assumptions, and reporting of failed as well as successful candidates. None of those claims is inferred from the synthetic demo.

本版没有进行样本外经济验证。真实研究还需要明确数据许可与覆盖、预先声明假设、区分开发和验证数据、采用合理执行成本，并记录失败候选。本演示不替代这些证据。
